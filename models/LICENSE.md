# Model assets — provenance and licence

This file is the compliance record for every 3D asset used by this project. It must
stay in sync with `scripts/fetch-models.mjs` and the `/attributions` page.

The model files themselves are **not** committed to this repository (see
`.gitignore`). Run `npm run models:fetch` to download them.

---

## Open3DModel — CC BY-SA 4.0

**Files:** all 36 `.glb` files in `public/models/` (~74 MB).

The exact source page for each individual asset is recorded in
`data/model-sources.json`, regenerated by `npm run models:discover`. That file is
the per-asset attribution record; the list is not duplicated here so the two
cannot drift apart.

**Created by:** the departments of anatomy of Leiden University Medical Center,
University Medical Center Utrecht, Maastricht University Medical Center and
KU Leuven (KULAK), in collaboration with anatomists from other Dutch universities.

**Project page:** https://anatomytool.org/open3dmodel
**Source files:** https://anatomytool.org/open3dmodel-create
**Licence:** Creative Commons Attribution-ShareAlike 4.0 International —
https://creativecommons.org/licenses/by-sa/4.0/

Open3DModel is itself derived from **Z-Anatomy** (CC BY-SA 4.0, Gauthier Kervyn and
Marcin Zielinski), which is in turn derived from **BodyParts3D/Anatomography**
(CC BY-SA 2.1 JP, Database Center for Life Science, Japan). That chain of
attribution is preserved here and on the `/attributions` page as ShareAlike
requires.

### Obligations we are meeting

1. **Attribution** — the `/attributions` page names every author and institution
   above, links to the original projects, and states the licence. Per-asset source
   pages are kept in `data/model-sources.json`.
2. **ShareAlike** — if we modify a model file, the modified file is published under
   CC BY-SA 4.0. Any such file is listed under "Modified assets" below.
3. **Indicate changes** — modifications are recorded below, not left implicit.

### Obligations that do NOT apply

Our website source code, the written explanations in `data/structures.json`, and the
curriculum mappings are independent works, not adaptations of the models. CC BY-SA's
ShareAlike term does not extend to them. (Merely displaying a CC BY-SA work on a page
does not make the page an adaptation.)

## Modified assets

*None yet.* Assets are currently served exactly as downloaded.

When a model is modified, add an entry here with: the file name, what changed, the
date, and a link to where the modified file is published under CC BY-SA 4.0.

> **Important:** modification must never include `gltf-transform join`, `prune`,
> `dedup --meshes`, or `gltfpack` node collapsing. Those merge geometry and delete
> the per-structure mesh names, which are the entire educational value of these
> files. `npm run models:verify` fails the build if names are lost.
